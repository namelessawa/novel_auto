## 结论

运行层验证为 **16/16 成功**：16 种已注册风格均生成了非空中文小说正文，无异常、无 Narrator 沉默。

人工风格符合度为：

- 通过：10
- 勉强通过：1
- 不通过：5

因此，本轮的严格风格通过率为 **62.5%（10/16）**；若把“勉强通过”计入可用，则为 **68.75%（11/16）**。

## 验证设计

为了把题材、人物和世界随机性尽量固定，本轮只真实冷启动一次 `steampunk_archive` 世界，然后把 tick 0 数据复制成 16 份；每份只改变 `TickState.style_preset_key`，分别推进同一个 tick。所有样本使用同一批初始角色（1A + 2B）、同一世界状态、同一模型和同一 endpoint。

验证时关闭 `WORLD_STALE_SKIP`，防止低事件密度导致无法审读；关闭 Narrator critic，避免二次改写掩盖风格 preset 的原始服从能力。16 个样本全部在第 1 tick 就生成正文，无需补跑第 2 tick。

本轮共产生：

- 正文：10,691 字
- tick token 记录：70,351 tokens（冷启动消耗未计入各 TickRuntime tracker）
- 每篇长度：414–964 字
- 每篇耗时：19.88–32.34 秒

## 问题归因

本轮失败不是生成链路故障，而是风格契约服从不足。共同的蒸汽朋克灾变素材对 `warm_healing` 等语义距离很远的风格构成了压力测试：Narrator 同时受到“不发明/不改变既定事实”和“禁止死亡、降低冲突”的约束，最终优先保留世界事实，牺牲风格。这个冲突可以解释治愈风格的失败，但解释不了 `classical_chapter` 的现代句法，也不能替 `black_humor` 和 `hot_blooded` 缺少核心读感开脱。

`melancholic` 暴露的是另一类问题：模型记住了“压抑、美但不温”，却漏掉同一 addendum 里的最低人物存在度硬约束。说明语义色调比结构性要求更容易被执行。
